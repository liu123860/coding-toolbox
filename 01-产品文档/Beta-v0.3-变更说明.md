## 三、档位机制说明（重要）

- 工具库共 130 个工具，每个工具有唯一序号 tier（1–130）。
- 安装包**真实预置 30 个**（tier 1–30）。
- 设置在 30/50/60/80/100/130 档位切换时，工具箱按档位显示对应数量的工具：选 50 显示 50 个，选 130 显示全部 130 个。
- 超过 30 的工具标记为「可下载」，点击后下载到设置指定的临时下载目录；带直链的自动下载并尝试解压，仅有官网页面的会打开官方页面并提示保存目录。
- 说明：安装包为一次性构建产物，已封死的内容无法在运行时改变；档位通过"预置 + 按需下载到本地"的方式实现"档位越高、可用内置工具越多"的效果。

## 四、默认目录（全部在程序文件目录内）

```
{程序安装目录}/
├── ToolboxApp.exe          # 主程序
├── _internal/              # 运行时
├── builtin/                # 30 个预置内置工具
├── toolbox/                # 默认安装/运行环境根目录
│   ├── downloads/          # 临时下载目录（默认）
│   ├── archives/           # 用户数据冻结归档目录（默认）
│   └── userdata/           # 各工具用户数据
└── config/config.json      # 用户设置
```

所有默认目录均可通过设置修改；修改时询问是否迁移已有文件；启动时逐项检查目录是否存在且可读写，失败给出明确报错。

## 五、保留的既有能力

- 每次启动通过自有服务器 JSON 清单检查新增/更新/下架工具（不爬第三方网站，合规）。
- 退出时询问是否冻结压缩用户数据、是否清理临时下载。
- 日志与备份统一写入 `L:\WorkBuddy临时文件\编程工具箱神器\`。
- 仅构建 x64 安装包，不做 32 位。
